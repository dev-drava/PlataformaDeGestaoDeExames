# PlataformaDeGestaoDeExames
Plataforma web em Flask com base de dados para gestão de exames e correção automática. Permite criar bancos de questões e provas, registar turmas, alunos e inscrições, realizar provas com correção automática das questões objetivas e consultar relatórios de notas por aluno e por exame. Inclui roles (operador/admin). Projeto escolar (GPSI).
